# 4. Timelines — điểm đồng bộ và mốc nghiệm thu

Tài liệu này **rút gọn** phần điều hành chung cho cả nhóm. Chi tiết epic, effort và checklist đầy đủ: [Timeline v4](../introduction/1.%20Timelines.md). Lịch học kỳ: **tuần 7 hiện tại, nộp tuần 10** — tuần 10 không mở tính năng mới.

---

## 4.1. Bốn sprint (không nhất thiết = 1 tuần)

| Giai đoạn | Thời gian (học kỳ) | Mục tiêu |
|---|---|---|
| Sprint 1 | Phần còn lại tuần 7 | Rà hiện trạng, contract, local/Docker/FFmpeg POC, Terraform data — **M0, M1** |
| Sprint 2 | Cuối tuần 7 → hết tuần 8 | Pipeline local đủ → cùng image lên AWS — **M2** |
| Sprint 3 | Đầu tuần 9 | CloudFront + API/HLS; scale 1→2 — **M3** |
| Sprint 4 | Phần còn lại tuần 9 | Benchmark, chaos, báo cáo, đóng băng — **M4** |
| Chốt | Tuần 10 | Rà hồ sơ, nộp — **M5** |

---

## 4.2. Bàn giao App ↔ Cloud

| Điểm đồng bộ | App cung cấp | Cloud cung cấp | Thời điểm |
|---|---|---|---|
| Local stack, Dockerfile | Lệnh chạy, cổng, env, health check | Compose, image, nginx; App review | Ngày 1–3 tuần 7 + cuối Sprint 1 |
| Schema DynamoDB | Code theo contract | Bảng LocalStack + Terraform | Sprint 1 |
| SQS message, upload limits | Producer/consumer, ffprobe | Queue, DLQ, alarm, lifecycle S3 | Sprint 1–2 |
| IAM | Danh sách quyền cần | Policy role API/Worker | Sprint 2 |
| Docker image | Code build OK | ECR, EC2 API, ASG Worker | Cuối Sprint 2 |
| SIGTERM / Spot | Worker xử lý dừng gọn | ASG Spot, scale-in protection | Sprint 2–3 |
| E2E / benchmark / chaos | Kịch bản, fix bug tích hợp | Môi trường AWS, dataset | Sprint 4 |

---

## 4.3. Mốc M0–M5 (tiêu chí ngắn)

| Mốc | Tiêu chí | Nếu trễ |
|---|---|---|
| **M0** | `make infra` + smoke OK; backend/worker **có thể** nối LocalStack từ IDE | Ưu tiên tuyệt đối; không mở P1 |
| **M1** | Contract reviewed; POC FFmpeg; Dockerfile; Terraform tạo S3/SQS/DDB trên AWS | Không giả định “đã xong” nếu chưa demo |
| **M2** (cuối tuần 8) | Upload → SQS → worker → HLS **trên AWS** | Cắt P1; chỉ luồng chính |
| **M3** (đầu tuần 9) | HTTPS một entry (CloudFront); worker scale 1→2 | Domain `*.cloudfront.net` đủ MVP |
| **M4** (cuối tuần 9) | Số liệu benchmark + 1 ca recovery; báo cáo + 2 diễn tập | Không dồn sang tuần 10 |
| **M5** (tuần 10) | Nộp + xác nhận; chỉ sửa blocker | Không deploy/scaling mới |

Hiện trạng repo so với các mốc: [2. Implementation status](2.%20Implementation%20status.md).

---

## 4.4. Việc không nằm trên đường găng nộp (P1 / cắt sớm)

- Webhook (A7), CI/CD Terraform đầy đủ (C6)
- Gắn domain riêng CloudFront (có thể dùng domain mặc định)
- 1080p output, AI subtitle/transcript/quiz

**Không cắt:** pipeline upload → queue → worker → HLS → COMPLETED, một phép đo co giãn, một phép đo phục hồi lỗi, giới hạn upload, báo cáo/demo.

Thứ tự cắt khi thiếu thời gian: xem mục 7 trong [Timeline v4](../introduction/1.%20Timelines.md).
