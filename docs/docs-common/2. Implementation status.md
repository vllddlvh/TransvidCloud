# 2. Hiện trạng triển khai trong repo

Bảng dưới phản ánh **code và cấu hình thực tế trong repository** (rà soát **31/10/2026**, tuần 9). Checklist epic trong [Timeline v4](../introduction/1.%20Timelines.md) chỉ được đánh dấu hoàn thành khi có bằng chứng chạy được — không suy ra từ tài liệu.

**Chú thích:** ✅ có và dùng được · 🟡 có khung / DRAFT / chưa nối end-to-end · ❌ chưa có hoặc stub

## 2.3. Definition of Done kỹ thuật (P0) — dùng khi tự kiểm tra nhóm

Chưa đạt các mục dưới thì **chưa** coi là “dự án chạy end-to-end” dù tài liệu đã viết:

1. `make smoke` pass trên máy ≥ 2 thành viên (LocalStack token OK) — ✅ trên máy Vũ 31/10; chưa xác nhận máy thứ hai.
2. Upload video mẫu → `confirm` → worker → `COMPLETED` + file HLS/thumbnail trên bucket output (local) — ✅ **worker mode** với message theo schema; ❌ qua API thật (backend chưa có).
3. Phát được qua `http://localhost:8000/media/.../master.m3u8` — ✅ trong `make e2e-worker` (nginx + ffprobe).
4. Cùng luồng trên AWS dev (M2) — ❌ chưa có AWS.
5. Một thí nghiệm scale 1→2 worker và một ca worker chết có số liệu (M3/M4) — 🟡 local: chaos SIGTERM/SIGKILL/DLQ pass, bench 1 vs 2 worker có số liệu; ❌ trên AWS.

Chi tiết runbook: [docs-cloud/4. Implement.md](../docs-cloud/4.%20Implement.md).

## 2.4. Cập nhật tài liệu này
