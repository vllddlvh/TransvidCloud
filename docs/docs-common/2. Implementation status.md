# 2. Hiện trạng triển khai trong repo

Bảng dưới phản ánh **code và cấu hình thực tế trong repository** (rà soát **21/10/2026**, tuần 7). Checklist epic trong [Timeline v4](../introduction/1.%20Timelines.md) chỉ được đánh dấu hoàn thành khi có bằng chứng chạy được — không suy ra từ tài liệu.

**Chú thích:** ✅ có và dùng được · 🟡 có khung / DRAFT / chưa nối end-to-end · ❌ chưa có hoặc stub

---

## 2.1. Tóm tắt một dòng

| Trục | Trạng thái |
|---|---|
| **Hợp đồng tích hợp** | 🟡 Bộ file trong `docs/contracts/` (DRAFT), local init khớp DynamoDB/SQS |
| **Local hạ tầng giả lập AWS** | ✅ Compose + LocalStack init + `make smoke` |
| **Ứng dụng (API / Worker / Web)** | ❌ Chỉ README; chưa `pom.xml`, `go.mod`, `package.json` |
| **Full stack local** | 🟡 Compose/nginx sẵn; `make up` cần Dockerfile + source App |
| **Terraform AWS** | 🟡 README module/env; chưa file `.tf` |
| **CI** | ✅ Workflow bỏ qua module chưa có manifest |
| **Deploy / E2E / Chaos** | 🟡 Script/workflow khung; e2e và chaos chưa triển khai |

**Mốc tiếp theo theo lịch:** M0 (`make infra` + App nối LocalStack) → M1 (contract chốt, POC FFmpeg, Dockerfile) — xem [4. Timelines](4.%20Timelines.md).

## 2.2. Chi tiết theo thành phần

### Hợp đồng (`docs/contracts/`)

| `openapi.yaml` | 🟡 DRAFT | Khung endpoint, chưa schema request/response đầy đủ |

| `video-state-machine.md` | 🟡 | Ranh giới API vs Worker đã mô tả |

### Local stack (`local/`, `docker-compose.yml`, `Makefile`)

| Hạng mục | Trạng thái | Ghi chú |
|---|---|---|

| `make infra`, `smoke`, `up`, `worker-scale` | ✅ | `make up` cần profile `full` + image backend/worker |
| `make chaos` | 🟡 | Script in “chưa triển khai” (A5/A8) |
| `make e2e` | 🟡 | Chỉ `up` + `smoke`; chưa kịch bản upload → COMPLETED |

### Ứng dụng

| Module | Trạng thái | Trong repo hiện có |
|---|---|---|
| `backend/` | ❌ | `README.md` (cấu trúc dự kiến, quy tắc) |
| `worker/` | ❌ | `README.md`, `testdata/README.md` |
| `frontend/` | ❌ | `README.md` |

Compose đã khai báo service `backend`/`worker` (profile `app`, `full`) và biến môi trường mẫu; **build sẽ fail** cho đến khi có Dockerfile và source.

## 2.3. Definition of Done kỹ thuật (P0) — dùng khi tự kiểm tra nhóm

Chưa đạt các mục dưới thì **chưa** coi là “dự án chạy end-to-end” dù tài liệu đã viết:

1. `make smoke` pass trên máy ≥ 2 thành viên (LocalStack token OK).
2. Upload video mẫu → `confirm` → worker → `COMPLETED` + file HLS/thumbnail trên bucket output (local).
3. Phát được qua `http://localhost:8000/media/.../master.m3u8`.
4. Cùng luồng trên AWS dev (M2).
5. Một thí nghiệm scale 1→2 worker và một ca worker chết có số liệu (M3/M4).

Chi tiết runbook: [docs-cloud/4. Implement.md](../docs-cloud/4.%20Implement.md).

## 2.4. Cập nhật tài liệu này

Khi merge PR có ý nghĩa (code App, Terraform apply, e2e pass), người merge **cập nhật một dòng** trong bảng 2.1 hoặc 2.2 và ghi ngày ở đầu file. Tránh để SRS/timeline ghi “đã xong” khi bảng này vẫn ❌.
