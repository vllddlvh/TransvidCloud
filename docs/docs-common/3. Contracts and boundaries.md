# 3. Hợp đồng tích hợp và ranh giới nhóm

Mọi giao diện giữa Backend, Worker, Frontend, Terraform và local init **phải khớp** thư mục [`docs/contracts/`](../contracts/README.md). Lệch contract thì **sửa code hoặc mở PR sửa contract** — không “sửa lặng” một phía.

Trạng thái hiện tại: các file contract đều ghi **DRAFT** — cần review cả 4 người trước M1.

## 3.2. Ranh giới App vs Cloud

```text
┌──────────────────────────────── App (Phương, Vũ) ────────────────────────────────┐
│  Code: backend/, worker/, frontend/                                              │
│  Trách nhiệm: nghiệp vụ, FFmpeg, UI, health endpoint, biến env runtime           │
│  Cung cấp cho Cloud: lệnh build/run, cổng, danh sách quyền AWS cần (DDB/SQS/S3)│
└──────────────────────────────────────────────────────────────────────────────────┘
                                        │
                    Contract-first PR   │
                                        v
┌────────────────────────────── Cloud (Lưu, Nguyên) ───────────────────────────────┐
│  local/: LocalStack init, nginx, smoke/chaos/e2e harness                         │
│  infra/terraform/: S3, SQS, DDB, VPC, EC2, ASG, CloudFront, IAM, SSM             │
│  scripts/ + GitHub Actions: build image, deploy API/Worker/frontend              │
│  Không deploy nội dung thư mục local/ lên AWS                                   │
└──────────────────────────────────────────────────────────────────────────────────┘
```

**Nguyên tắc đã chốt:**

- Cùng Docker image local và cloud; khác biến môi trường (`AWS_ENDPOINT_URL` có/không).
- Cloud sở hữu đường đi **local → cloud** (`make up` rồi cùng image lên ECR/EC2).
- App không hard-code bucket/queue ARN; đọc tên từ env/SSM do Cloud cấp.

## 3.3. Ai được ghi gì (tránh tranh chấp DynamoDB)

| Dữ liệu / trạng thái | API | Worker |
|---|---|---|
| Tạo video, `title`, `originalKey`, UPLOADING | ✅ | ❌ |
| confirm → PENDING, gửi SQS | ✅ | ❌ |
| PROCESSING, COMPLETED, FAILED_* | ❌ | ✅ |
| `assets` sau transcode | ❌ | ✅ |
| Bảng users, projects, apikeys | ✅ | ❌ (IAM worker không ghi) |

Worker **idempotent:** video đã `COMPLETED` → bỏ qua job, xóa message SQS.

## 3.4. Quy trình đổi contract

1. PR (ưu tiên chỉ `docs/contracts/` hoặc kèm code thích ứng), nhãn `contract-change`.
2. **Approve cả App và Cloud** (duyệt trực tiếp trên PR — không dùng CODEOWNERS).
3. Đổi message SQS không tương thích → tăng `schemaVersion` và cập nhật cả producer + consumer.
4. Cập nhật đồng bộ: `local/localstack/init/`, Terraform module liên quan, tài liệu worker/backend nếu có ví dụ cũ.

---

## 3.5. Điểm đồng bộ thường gặp lỗi tích hợp

| Chủ đề | Cần thống nhất |
|---|---|
| Tên bucket / queue / bảng | `tvc-local-*` vs `tvc-dev-*`; biến trong `.env.example` |
| Presigned URL | Path-style local; host browser vs host container |
| Trường `assets` | Lưu S3 key vs URL đầy đủ — API ghép `/media/` (đề xuất trong worker docs) |
| FAILED_* vs retry | Validation: ACK message; transcode/storage: để SQS retry → DLQ sau 3 lần |
| Metric scaling | `BacklogPerInstance` — worker `metricpub` nếu ASG min=0 |
