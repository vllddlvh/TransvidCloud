## Tiếp tục C0 trên Windows

Mở Docker Desktop và chờ Engine sẵn sàng. Tại root repo chạy PowerShell:

```powershell
docker version
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
# Điền LOCALSTACK_AUTH_TOKEN trong .env theo image đang dùng; không chia sẻ token.
docker compose up -d localstack
docker compose logs --tail=100 localstack
# Chờ log [init] Hoàn tất trước lệnh sau:
powershell -NoProfile -ExecutionPolicy Bypass -File local/scripts/smoke-test.ps1
```

Chỉ đánh dấu hạ tầng local đạt khi smoke chạy thành công. M0 còn yêu cầu backend/worker kết nối được LocalStack. Không dùng smoke thay bằng chứng E2E hoặc quyền IAM trên AWS.

Mỗi lần nghiệm thu ghi commit, môi trường, lệnh chạy, kết quả và người kiểm tra; không ghi secret. Các contract còn DRAFT phải được review chung trước M1.
