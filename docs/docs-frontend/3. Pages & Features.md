# 3. Màn hình và tính năng

Mô tả từng trang của SaaS Web và luồng người dùng. Chi tiết endpoint, request/response sẽ ghi trong `5. API Integration.md` khi backend chốt contract; trang này mô tả ở mức hành vi và UI.

## Tổng quan layout

Layout cố định theo design system: sidebar trái 240px (điều hướng) + header 56px (tìm kiếm, tài khoản) + vùng nội dung. Xem [4. Design System.md](4.%20Design%20System.md).

```
┌────────┬──────────────────────────────────────┐
│        │ Header: logo · tìm kiếm · user        │
│ Sidebar├──────────────────────────────────────┤
│ 240px  │ Nội dung trang (thay đổi theo route)  │
└────────┴──────────────────────────────────────┘
```

## 1. Đăng nhập (`/login`)

- Form email + mật khẩu → đăng nhập JWT.
- Lưu token (localStorage hoặc cookie tùy backend), redirect sang danh sách project.
- Lỗi sai thông tin: thông báo inline, không reload trang.
- Đăng ký qua UI **không thuộc MVP** — tạo tài khoản bằng API/curl khi test.
- Khi token hết hạn: redirect về login kèm thông báo phiên đã hết hạn.

## 2. Danh sách project (`/projects`)

- Danh sách project của user (card hoặc bảng), mỗi project: tên, số video, thời gian tạo.
- Nút "Tạo project": form tên + mô tả.
- Click project → danh sách video của project đó.

## 3. Danh sách video (`/projects/:id/videos`)

- Danh sách video: thumbnail (nếu đã có), tên, dung lượng, thời lượng, **trạng thái**, thời gian tạo.
- Trạng thái hiển thị theo state machine (`docs/contracts/video-state-machine.md`):

| Trạng thái | Hiển thị | Ghi chú |
|---|---|---|
| `UPLOADING` | "Đang tải lên" | Hiếm khi thấy — chỉ khi upload bị gián đoạn |
| `PENDING` | "Đang chờ xử lý" | Đã confirm, chờ worker nhận |
| `PROCESSING` | "Đang xử lý" | Có thể kèm spinner/progress |
| `COMPLETED` | "Hoàn tất" | Có thể phát, hiện link streaming + mã nhúng |
| `FAILED_VALIDATION` | "Lỗi: file không hợp lệ" | Vượt thời lượng/độ phân giải hoặc không phải video |
| `FAILED_TRANSCODE` / `FAILED_STORAGE` | "Lỗi xử lý" | Lỗi phía worker; có thể được retry |

- **Polling:** khi có video đang `PENDING`/`PROCESSING`, poll chi tiết video theo khoảng thời gian cố định (đề xuất 3–5 giây); dừng khi mọi video về trạng thái cuối.
- Nút "Tải video lên" mở luồng upload (bên dưới).

## 4. Luồng upload (modal hoặc trang)

Luồng presigned upload — video **không đi qua API**:

```
Chọn file
   │  Kiểm tra client (chỉ để UX, không phải lớp bảo vệ):
   │  dung lượng ≤ 200 MB, đuôi mp4/mov/mkv/webm
   ▼
POST /videos (khai báo sizeBytes, contentType)
   │  API từ chối 413/422 nếu vượt giới hạn → hiện lỗi, dừng
   ▼
Nhận presigned URL (hết hạn 15 phút)
   │
   ▼
PUT file thẳng lên S3 (kèm Content-Length đã khai báo)
   │  Lỗi mạng/S3 → nút thử lại
   ▼
POST /videos/:id/confirm
   │  API HeadObject kiểm tra rồi chuyển PENDING, gửi SQS
   ▼
Video xuất hiện trong danh sách, trạng thái PENDING → poll
```

- Hiển thị tiến trình upload bằng `XMLHttpRequest` progress (fetch không hỗ trợ upload progress).
- Sau `confirm`: đóng modal, người dùng theo dõi trạng thái trong danh sách.

## 5. Chi tiết video (`/videos/:id`)

- Thông tin đầy đủ: trạng thái, errorCode nếu lỗi, assets khi hoàn tất.
- Khi `COMPLETED`:
  - **Trình phát HLS** (hls.js) phát master playlist — đường dẫn tương đối `/media/...`.
  - **Link streaming**: nút copy URL master playlist.
  - **Mã nhúng**: nút copy đoạn `<iframe>` trỏ tới trang nhúng của video *(việc cắt giảm đầu tiên nếu thiếu thời gian — xem [2. Timelines.md](2.%20Timelines.md#4-thứ-tự-cắt-giảm))*.
- Khi `FAILED_*`: hiện nguyên nhân từ `errorCode` kèm gợi ý (vd vượt 5 phút, quá 1080p).

## 6. Trang nhúng (embed) — nếu giữ mã nhúng

- Trang tối giản chỉ chứa player, không sidebar/header.
- Chỉ cho phép phát khi video `COMPLETED`.

## Xử lý lỗi chung

| Tình huống | Hành vi UI |
|---|---|
| 401 token hết hạn | Redirect login + thông báo |
| 403 tài nguyên của người khác | Thông báo "Không có quyền" |
| 413/422 vượt giới hạn upload | Thông báo lỗi cụ thể ngay tại bước upload |
| Lỗi mạng / API 5xx | Thông báo toast + nút thử lại |
| Polling lỗi liên tục | Hiển thị trạng thái "không xác định", nút tải lại trang |
