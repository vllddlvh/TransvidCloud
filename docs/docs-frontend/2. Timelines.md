# 2. Timelines — Epic A6: Frontend tối thiểu

Nguồn: epic A6 trong [`docs/introduction/1. Timelines.md`](../introduction/1.%20Timelines.md) — 2,0 pd, Sprint 2–3, P0, chủ nhiệm: Vũ. Trang này bóc nhỏ A6 thành task để theo dõi tiến độ, kèm ràng buộc từ mốc chung.

**Hiện tại tuần 7, hạn nộp tuần 10.** Sprint 2 là phần sau tuần 7–8; Sprint 3 đầu tuần 9; Sprint 4 phần còn lại tuần 9. Vũ còn phụ trách worker nên 2,0 pd frontend là baseline phải cân đối chung, không phải capacity riêng. Tuần 7 chốt contract và chuẩn bị khung; cuối tuần 9 đóng băng, tuần 10 chỉ rà/nộp hồ sơ.

## 1. Task theo sprint

### Cuối tuần 7–8 / Sprint 2 — khung + luồng chính

- [ ] **F1. Dựng khung project** (0,5 pd)
  - Vite + React + TypeScript, cấu hình dev qua nginx cổng 5173 → `localhost:8000`
  - Áp dụng design token từ [Frontend template](Frontend%20template/) (sidebar, header, layout) — xem [4. Design System.md](4.%20Design%20System.md)
  - Router + khung trang: login, projects, videos, video detail
- [ ] **F2. Đăng nhập + project** (0,5 pd)
  - Trang login (JWT), lưu token, guard trang cần đăng nhập
  - Danh sách project, tạo project
  - *Phụ thuộc: A2 backend có `/auth/login`, `/projects` (Phương)*
- [ ] **F3. Upload bằng presigned URL** (0,5 pd)
  - Chọn file, kiểm tra client: dung lượng ≤ 200 MB, định dạng mp4/mov/mkv/webm
  - Xin presigned URL → PUT thẳng S3 → gọi `confirm`
  - *Phụ thuộc: A3 backend có `POST videos` + `confirm` (Phương)*

### Cuối tuần 8 đến đầu tuần 9 / Sprint 3 — trạng thái + player

- [ ] **F4. Danh sách video + trạng thái (polling)** (0,25 pd)
  - Danh sách video theo project, hiển thị trạng thái theo state machine
  - Polling chi tiết video khi đang `PENDING`/`PROCESSING`
- [ ] **F5. Trình phát HLS + link streaming + mã nhúng** (0,25 pd)
  - hls.js phát master playlist khi video `COMPLETED`
  - Copy link streaming; đoạn mã nhúng `<iframe>` dạng copy
  - *Phụ thuộc: A4 worker ra HLS output + C4 CloudFront `/media/*` (Nguyên, Lưu)*

## 2. Đối chiếu mốc chung

| Mốc | Yêu cầu liên quan frontend | Ghi chú |
|---|---|---|
| M2 (cuối tuần 8) | Pipeline AWS; frontend upload được nếu API đã sẵn sàng | Nếu frontend chưa xong, kiểm chứng pipeline bằng curl; F3 phải xong trước M3 đầu tuần 9 |
| M3 (đầu tuần 9) | SaaS qua CloudFront, domain mặc định đủ cho MVP | F5 cần `/media/*`; phát local trước khi nối cloud |
| M4 (cuối tuần 9) | E2E/benchmark, báo cáo và hai lần diễn tập | Hỗ trợ Lưu debug, đóng băng frontend; không thêm màn hình mới |
| M5 (tuần 10) | Rà bản build/hướng dẫn và bộ hồ sơ nộp | Sẵn sàng đầu tuần, nộp theo hạn môn học |

## 3. Phụ thuộc chéo

| Cần gì | Từ ai | Khi nào |
|---|---|---|
| Endpoint auth, project, video, confirm chốt trong `contracts/openapi.yaml` | Phương (A2, A3) | Sprint 1–2 |
| HLS output đúng key/Content-Type để phát được | Vũ tự làm (A4) + Lưu (C1 CORS) | Sprint 2 |
| CloudFront behavior `/`, `/api/*`, `/media/*` | Nguyên (C4), Lưu hosting React | Sprint 3 |
| CORS presigned PUT nếu frontend và API khác origin | Phương (A2) | Sprint 2 |

## 4. Thứ tự cắt giảm

Theo mục 7 của [Timelines chung](../introduction/1.%20Timelines.md), frontend cắt theo thứ tự:

1. Bỏ đoạn mã nhúng — chỉ giữ trình phát và link streaming (việc cắt đầu tiên của A6).
2. Sau đó bỏ trang video detail nếu quá tải — phát ngay trong danh sách.

Không được cắt: upload qua presigned URL và hiển thị trạng thái tới `COMPLETED` — đó là luồng cốt lõi của demo.
