# 1. Giới thiệu frontend

Frontend là giao diện **SaaS Web** của TransVidCloud: nơi người dùng cuối đăng nhập, quản lý project, upload video và xem kết quả sau khi worker chuyển mã HLS. Đây là một trong hai cách dùng của nền tảng (cách còn lại là Developer API — không thuộc phạm vi frontend).

- **Phụ trách:** Vũ (Lưu hỗ trợ hosting lên S3/CloudFront).
- **Epic tương ứng:** A6 — Frontend tối thiểu (Sprint 2–3: cuối tuần 7–8 đến đầu tuần 9, P0). Hiện tại tuần 7; kiểm chứng/đóng băng cuối tuần 9, nộp BTL tuần 10. Chi tiết task: [2. Timelines.md](2.%20Timelines.md).

## Phạm vi (MVP)

| Có | Không có |
|---|---|
| Đăng nhập (JWT) | Đăng ký qua UI *(tạm dùng API/curl; có thể thêm nếu kịp)* |
| Danh sách / tạo project | Quản lý thành viên, phân quyền trong UI |
| Upload qua presigned URL, kiểm tra dung lượng/định dạng phía client | Quản lý API key qua UI |
| Danh sách video + trạng thái (polling) | Webhook, thông báo realtime (SSE/WebSocket) |
| Trình phát HLS (hls.js), link streaming, mã nhúng | Chỉnh sửa video, phụ đề, nhiều bản chất lượng chọn tay |

Nếu thiếu thời gian, cắt theo thứ tự trong [2. Timelines.md](2.%20Timelines.md#4-thứ-tự-cắt-giảm) — việc cắt đầu tiên là bỏ mã nhúng, chỉ giữ trình phát và link streaming.

## Tech stack

| Thành phần | Lựa chọn | Ghi chú |
|---|---|---|
| Framework | React + Vite | Dev server cổng 5173, truy cập qua `http://localhost:8000` khi bật stack `full` |
| Trình phát | hls.js | Phát HLS trên mọi trình duyệt hiện đại; Safari có thể dùng HLS native |
| Gọi API | fetch/axios với client sinh hoặc viết theo `docs/contracts/openapi.yaml` | Chi tiết endpoint chờ backend chốt, sẽ ghi trong `5. API Integration.md` |
| Style | CSS token từ [Frontend template](Frontend%20template/) | Xem [4. Design System.md](4.%20Design%20System.md) |
| Ngôn ngữ | TypeScript | Ưu tiên kiểu cho trạng thái video và assets |

## Cấu trúc thư mục dự kiến

```
frontend/src/
├── pages/     trang: login, projects, videos, video detail
├── api/       client gọi /api/* (sinh/viết theo docs/contracts/openapi.yaml)
└── player/    HLS player và mã nhúng
```

## Nguyên tắc

1. **Đường dẫn tương đối:** luôn gọi `/api/...`, `/media/...` — không hard-code origin. Cùng code chạy được ở local (nginx) và cloud (CloudFront).
2. **Upload không đi qua API:** xin presigned URL từ API, PUT thẳng lên S3, rồi gọi `confirm`. API không bao giờ nhận bytes video.
3. **Client check chỉ để UX:** kiểm tra dung lượng/định dạng phía client để chặn sớm, nhưng không phải lớp bảo vệ. Nguồn sự thật về giới hạn: `docs/contracts/upload-limits.md`.
4. **Contract-first:** endpoint, trạng thái video, key S3 lấy từ `docs/contracts/` — muốn đổi thì sửa contract trước.
5. **Polling cho trạng thái:** trạng thái video (xem `docs/contracts/video-state-machine.md`) cập nhật bằng polling trong MVP; không realtime.
