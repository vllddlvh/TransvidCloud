# 4. Design System

Hệ thiết kế của TransVidCloud Web, chuẩn hóa từ bản tham chiếu **YouTube-style "minimalist broadcast console"** trong [`Frontend template/`](Frontend%20template/). Nguyên tắc gốc: giao diện tối giản, phẳng, không cạnh tranh với nội dung — rất hợp một app quản lý video.

File gốc đầy đủ: [`Frontend template/DESIGN.md`](Frontend%20template/DESIGN.md). Trang này là bản rút gọn + hướng dẫn áp dụng cho app; template là nguồn sự thật về giá trị token.

## 1. Màu

| Token | Giá trị | Dùng cho |
|---|---|---|
| `--color-canvas-white` | `#ffffff` | Nền trang, sidebar, card, input |
| `--color-youtube-ink` | `#0f0f0f` | Text chính, icon stroke, nhãn button — **không dùng `#000000`** |
| `--color-graphite` | `#606060` | Text phụ, metadata, timestamp, trạng thái |
| `--color-ash` | `#909090` | Text mờ, disabled, placeholder |
| `--color-mist` | `#c6c6c6` | Hairline border, divider |
| `--color-silver` | `#d3d3d3` | Border button, input outline |
| `--color-signal-blue` | `#065fd4` | Link, button outline (đăng nhập, hành động phụ) — **không làm màu CTA filled** |
| `--color-play-red` | `#ff0000` | Chỉ riêng logo play triangle — **không dùng làm màu chức năng** |

Với trạng thái video (không có trong template), dùng graphite/ash cho chờ/xử lý và một đỏ lỗi riết theo token (`--color-play-red` chỉ dành logo — lỗi dùng `#cc0000` hoặc token bổ sung `--color-error`, ghi rõ khi thêm).

## 2. Typography

- **Roboto** cho toàn bộ giao diện (400/500/700), fallback Inter, system-ui.
- Quy mô: caption 10px · body 14px · heading 20px — **không vượt 20px** ngoài logo.
- Nav item: 14px; body copy: 13–14px; metadata/timestamp: 12px graphite.
- Không dùng YouTube Sans ngoài wordmark.

## 3. Khoảng cách & bo góc

- Base unit **4px**; scale: 4, 8, 12, 16, 24, 32, 240 (sidebar).
- Khoảng cách section 24px, card padding 16px, gap phần tử 12px.
- Bo góc: button/input **18px (pill)**, card/icon **10px**.

## 4. Component chuẩn

| Component | Mô tả ngắn |
|---|---|
| **Sidebar** (240px, fixed) | Nav chính: Projects, Videos (của project đang chọn), link footer. Item 40px cao, icon 24px + label 14px; active = ink `#0f0f0f` + hover fill xám rất nhạt |
| **Header** (56px, sticky) | Trái: hamburger + logo; giữa: search (tùy chọn, P1); phải: icon button + avatar/Sign in |
| **Pill button outline** | Border + text `#065fd4`, nền trắng, radius 18px, padding 8/16 — nút đăng nhập, hành động phụ |
| **Pill button neutral** | Nền trắng, border `#d3d3d3`, text ink — nút hành động không cần nhấn mạnh ("Tạo project") |
| **Icon button** | 40×40, icon 24px stroke 2px, không border — hamburger, more |
| **Search input** | Pill 18px radius, cao ~40px, border `#d3d3d3`, placeholder ash |
| **Card** | Nền trắng, border 1px `#c6c6c6`/`#d3d3d3`, radius 10px, padding 16px — dùng cho card project, card video, notification |
| **Video card** | Thumbnail 16:9 (từ worker), tên, metadata 12px graphite, badge trạng thái |

## 5. Do's & Don'ts (tóm tắt)

**Do**
- Tách section bằng khoảng trắng, không dùng divider.
- Border 1px để định nghĩa card — không dùng shadow.
- Text chính luôn `#0f0f0f`, phụ `#606060`.

**Don't**
- Không dùng `#000000`, không drop shadow, không gradient — hệ thống phẳng cố ý.
- Không dùng `#065fd4` làm nền button filled; không dùng `#ff0000` ngoài logo.
- Không vượt 20px font size.

## 6. Áp dụng vào code

Template kèm sẵn 3 file dùng trực tiếp:

| File | Dùng thế nào |
|---|---|
| [`variables.css`](Frontend%20template/variables.css) | Import vào global CSS (`:root`) — mọi component dùng var(--...), không hard-code giá trị |
| [`theme.css`](Frontend%20template/theme.css) | Class tiện ích theo theme |
| [`tokens.json`](Frontend%20template/tokens.json) | Nguồn cấu trúc nếu sinh style bằng công cụ (vd Tailwind `@theme`) |

Quy ước: **mọi màu/kích thước mới phải khai báo thành token** trong `variables.css`, đặt tên theo `--color-*` / `--spacing-*` / `--radius-*`, rồi tham chiếu trong component. Không viết hex trực tiếp trong JSX.

## 7. Ánh xạ component → trang

| Trang | Component chính dùng |
|---|---|
| Login | Pill button outline, input pill |
| Projects | Sidebar, Header, Card, Pill button neutral (tạo project) |
| Videos | Sidebar, Header, Video card, upload modal (Card) |
| Video detail | Card thông tin, player area, button copy |
| Embed | Chỉ player, không chrome |
