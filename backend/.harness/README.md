# Harness Project Configuration

Điền `project-config.md` để ghi stack, modules, cách chạy và conventions. Điền `verify-commands.txt` bằng các lệnh verification đã được team xác nhận.

`verify-commands.txt` được `scripts/verify.sh` thực thi qua Bash. Chỉ đặt các lệnh tin cậy, đã review và an toàn để chạy trong môi trường hiện tại. Script không tự phát hiện đúng/sai về mặt nghiệp vụ và không thay thế CI/CD.
