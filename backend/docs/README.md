# Project Documentation

`docs/` chứa kiến thức tương đối ổn định về hệ thống. Không dùng thư mục này để lưu trạng thái task ngắn hạn hoặc đặc tả của từng feature.

Các file bên dưới là template. Thay `TODO(SETUP)` bằng thông tin đã xác minh trong repository; xóa nội dung không áp dụng.

- `architecture.md`: kiến trúc và module boundaries.
- `development-setup.md`: cài đặt, khởi động và cấu hình môi trường.
- `engineering-standards.md`: coding conventions và hard constraints.
- `testing-strategy.md`: tầng test và cách chọn verification.
- `modules/`: hướng dẫn module nếu Monorepo cần.
- `decisions/`: Architecture Decision Records (ADR).
