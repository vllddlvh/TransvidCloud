# Project Feature Backlog

`features.md` là danh mục feature cấp project. Mỗi feature chỉ xuất hiện một lần ở đây. Tài liệu chi tiết và task implementation đặt tại `specs/<feature>/` (thường do GitHub Spec Kit tạo).

- Không đưa từng implementation task vào backlog.
- Chỉ đổi state theo bằng chứng và quy tắc trong `AGENTS.md`.
- `verified` và `completed` là hai trạng thái khác nhau: verified là kiểm tra kỹ thuật pass; completed là đã được chấp nhận theo quy trình human review/merge.
- Nếu feature chưa đủ rõ hoặc chưa được ưu tiên, có thể giữ ở mức ý tưởng/planned mà chưa tạo bộ spec đầy đủ.
