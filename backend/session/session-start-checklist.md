# Session Start Checklist

- [ ] Đọc `AGENTS.md` và hướng dẫn module liên quan.
- [ ] Đọc `PROGRESS.md`.
- [ ] Đọc `backlog/features.md` và xác định feature đang active/được giao.
- [ ] Kiểm tra `git status --short`, branch và thay đổi chưa commit.
- [ ] Đọc spec/plan/tasks của feature; xác minh đúng feature path.
- [ ] Đọc docs/module guide cần thiết; không nạp toàn bộ docs nếu không liên quan.
- [ ] Kiểm tra environment và lệnh verification đã cấu hình.
- [ ] Chạy baseline phù hợp hoặc ghi rõ blocker.
- [ ] Chốt task contract, scope và acceptance criteria trước implement.
