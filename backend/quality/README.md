# Quality and Evidence

Thư mục này lưu trạng thái chất lượng tổng hợp và bài học cải tiến Harness. Kết quả gốc nên trỏ đến test output, CI run, PR hoặc artifact có thể truy cập; tránh copy log lớn vào Git.

- `quality-status.md`: snapshot chất lượng theo module hoặc release.
- `failure-log.md`: các failure đáng chú ý và nguyên nhân gốc.
- `review-feedback.md`: review findings lặp lại và cách promote thành check tự động.
- `templates/`: mẫu task contract và evidence.

Không lưu secrets, customer data hoặc log chứa thông tin nhạy cảm.
